## A. Runtime / operations (server.mjs, config, deps)

1. **Auth for /api/ask is keyed on the bind host, not the client.** `authorizeAskRequest` skips the token whenever `config.host` is loopback. Put nginx/cloudflared in front of the 127.0.0.1 bind and every internet visitor gets unauthenticated Ask AI and shares one rate-limit bucket (all traffic arrives as 127.0.0.1). Not exposed today (no tunnel/proxy running). Fix: `app.set('trust proxy', ...)` and check `req.ip`, or drop the loopback bypass when `X-Forwarded-For` is present.
2. **`runs/latest.json` is written non-atomically** (`writeFileSync`, server.mjs:378). Crash mid-write → dashboard falls back to loading page on next boot. Same pattern: `data/tle/active.json` (3.5 MB, tleCatalog.mjs:191), `airwatchBaseline.mjs:72`. Fix: write `.tmp` then `renameSync`. `memory.mjs` already does this (minus fsync).
3. **No shutdown timeout.** `shutdown()` awaits `httpServer.close()` and Discord stop with no deadline; systemd will SIGKILL after 90 s. Add `setTimeout(()=>process.exit(1), 10_000).unref()`.
4. **`uncaughtException` handler logs and continues.** With `Restart=on-failure` in the unit, exiting is safer than running in unknown state.
5. **No Express error handler.** Any future async handler that forgets try/catch returns Express 5's default HTML stack page (NODE_ENV is set to production in the unit, so it's mitigated there, but not for `npm start`).
6. **Dependencies:** `node_modules` dated Jun 8 predates the `undici` override in package.json; 18 extraneous packages (cheerio tree, Telegram scraper leftover); `npm audit` shows ws (high, via discord.js) and undici (moderate). Run `npm ci`, then `npm audit`.
7. **Disk at 87 %** (3.9 GB free). Crucix itself is small (runs 7 MB, data 8.6 MB) but cold memory archives are append-only (37 daily files, no retention).
8. `/api/satellite-passes?zip=<anything>` silently uses Independence, LA (only entry in the observer table) and returns 200 with no flag. Each call fires ~8 requests at tle.ivanstanojevic.me, no caching, ~4 s. That host is documented in-repo as unusable (508 after 2–3 requests) — both `lib/space/satellitePasses.mjs` and `apis/sources/space.mjs` still use it while `services/space/tleCatalog.mjs` already caches the CelesTrak set.
9. `.env` loader (`apis/utils/env.mjs`) doesn't strip quotes or `export`; `.env.example` is missing BLS_API_KEY, REDDIT_CLIENT_ID/SECRET, RELIEFWEB_APPNAME, MISTRAL/MINIMAX keys, OLLAMA_MODEL, ASK_AI_MAX_CONTEXT_CHARS, CRUCIX_LANG.
10. README still mentions "corridor flow effects" (removed), and `docker-compose.yml`/README use 3117 while the Pi runs 3118 (expected, env override).

## B. Sources (apis/) — the big systemic issue

**Silent all-zero success.** `safeFetch` returns `{error}` as a value; ~2/3 of sources do `data?.field || []` and report zero counts plus reassurance text when the upstream is down. Confirmed cases: safecast ("All monitored nuclear sites within normal radiation levels"), noaa (totalSevereAlerts 0), firms (bad key → HTTP 200 text → "No detections"), patents, comtrade, eia, fred, treasury, yfinance, bluesky, reddit, epa (and epa then overwrites `lastSuccessfulBriefing` with the empty result).
`runSource` (briefing.mjs:61) counts any resolved value as `ok`, so `sourcesOk` in the log/JSON overstates health; inject.mjs does inspect `.error` so the UI is right.
Fix: one `unwrap()` helper that throws on `res.error`/`res.rawText`, and `status: 'degraded'` in runSource when `data.error`.
